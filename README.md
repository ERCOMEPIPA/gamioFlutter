Este repositorio contiene la aplicación móvil oficial de **Gamio**, desarrollada con **Flutter** para iOS y Android como parte del Trabajo de Fin de Grado (TFG).

## 🛠️ Características Móviles

* ⚡ **Sincronización en Tiempo Real:** Chat y sistema de matchmaking conectado a Supabase.
* 👥 **Búsqueda de Compañeros (LFG):** Filtrado y conexión directa con jugadores por plataformas y videojuegos.
* 🎁 **Gamificación y Recompensas:** Reivindicación de misiones y recompensas estéticas.
* 📱 **Multiplataforma:** Optimizado para Android e iOS.

---

## 🚀 Cómo Ejecutar la Aplicación Móvil

### 1. Requisitos Previos
* Flutter SDK (v3.0+)
* Android Studio / Xcode
* Un dispositivo físico o un emulador configurado

### 2. Instalación y Ejecución
```bash
# Obtener las dependencias de pub.dev
flutter pub get

# Ejecutar la aplicación en modo desarrollo
flutter run
```
